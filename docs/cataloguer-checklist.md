# Λίστα ελέγχου: Καταλογογράφος στο admin της Strapi

Προετοιμασία: `nvm use 20 && npm run develop`, σύνδεση ως Super Admin.

## Ρόλος και πρόσβαση
- [ ] Settings → Administration Panel → Roles: υπάρχει ο ρόλος «Καταλογογράφος».
- [ ] Settings → Users → Invite new user με ρόλο «Καταλογογράφος». Σύνδεση με αυτόν τον χρήστη.
- [ ] Στο Content Manager φαίνονται Έντυπα, Πρόσωπα, Εκδότες, Θέματα DDC, Ρόλοι συντελεστών (με επεξεργασία) και Βιβλιοθήκες, Αντίτυπα (μόνο ανάγνωση). Δεν φαίνεται το «User» των users-permissions.

## Προβολή
- [ ] Σε Έντυπα, Πρόσωπα, Εκδότες: «Configure the view» → απόκρυψη των `searchKey` και `matchKey` από την οθόνη επεξεργασίας (ούτως ή άλλως ξαναϋπολογίζονται σε κάθε αποθήκευση).

## Ουρά ελέγχου
- [ ] Πρόσωπα → Filters → `reviewed` is `false`: εμφανίζονται οι τοπικές εγγραφές.
- [ ] Διόρθωση ονόματος και `reviewed = true` → η αποθήκευση πετυχαίνει.
- [ ] Δημιουργία προσώπου με όνομα που υπάρχει ήδη → μήνυμα «Υπάρχει ήδη εγγραφή…».

## Συντελεστές
- [ ] Σε ένα έντυπο: προσθήκη συντελεστή χωρίς ρόλο → μήνυμα «Κάθε συντελεστής χρειάζεται πρόσωπο και ρόλο».
- [ ] Αλλαγή σειράς συντελεστών με drag & drop → η σειρά διατηρείται μετά την αποθήκευση.

## Συγχώνευση
- [ ] Πρόσωπο-διπλότυπο → `mergeInto` = σωστό πρόσωπο → Save → η εγγραφή εξαφανίζεται και τα έντυπά της δείχνουν το σωστό πρόσωπο.
- [ ] Συγχώνευση δύο προσώπων της Biblionet → μήνυμα απόρριψης.
- [ ] Συγχώνευση εκδοτών που θα έκανε δύο μπροσούρες ίδιες (ίδιος τίτλος και έτος) → μήνυμα «Υπάρχει ήδη…». Πρώτα συγχωνεύονται οι μπροσούρες και μετά οι εκδότες.
- [ ] Τοπική μπροσούρα → `mergeInto` = άλλη μπροσούρα → τα αντίτυπα μεταφέρονται και οι αριθμοί αντιτύπων δεν συγκρούονται.
- [ ] Τοπικό πρόσωπο που αργότερα ήρθε και από τη Biblionet με το ίδιο όνομα → `mergeInto` = η εγγραφή της Biblionet → η συγχώνευση πετυχαίνει.
- [ ] Μετά από κάθε συγχώνευση, επιστροφή στη λίστα: η φόρμα δείχνει ακόμα την εγγραφή που διαγράφηκε.

## Σχέσεις από την «άλλη πλευρά»
- [ ] Στη φόρμα εκδότη, σύνδεση ενός εντύπου στο πεδίο `books` → μήνυμα «Ο εκδότης ενός εντύπου αλλάζει από την εγγραφή του εντύπου».
- [ ] Στη φόρμα εντύπου, αλλαγή στο πεδίο `copies` → μήνυμα «Τα αντίτυπα αλλάζουν μόνο από τη συλλογή «Αντίτυπα»».

## Διαγραφές
- [ ] Διαγραφή προσώπου που χρησιμοποιείται → μήνυμα «…Χρησιμοποιήστε συγχώνευση».
- [ ] Διαγραφή εντύπου με αντίτυπα → μήνυμα «Το έντυπο έχει αντίτυπα…».
